# 本地学习库（智能文档学习库）

> 将 PDF、Word、Markdown 原始文档统一复制到可自行指定的资料库目录，建立原文索引，并通过 1–25 字关键词快速查找原文。  
> 所有数据仅在本机处理，不上传服务器；搜索结果只来自文档原始文字，**不会进行 AI 概括、改写或联网查询**。

## ✨ 主要用途

- 将分散的 PDF、Word、Markdown 资料统一归档到本地资料库
- 用 1–25 字关键词快速检索原文片段，并标黄关键词
- 在软件内部阅读并批注 PDF（高亮、下划线、手写、备注等）
- 从试卷中逐题检索知识库原文，生成答案与出处
- 标记重点考点，并统计答案出处引用排名

## 📌 功能特点

- **完全离线运行**：数据仅保存在本机，不上传服务器
- **多格式支持**：支持 `.pdf`、`.docx`、`.md`、`.markdown` 等格式导入与索引
- **关键词检索**：支持 1–25 字关键词，结果按关键词出现次数排序，以卡片形式展示原文片段
- **内置 PDF 阅读器**：支持标签页阅读、全文检索、精确逐字选字、高亮、下划线、手写、备注、批注清单及批注版另存
- **试卷答案查找**：逐题检索原文，生成答案 Markdown、答案 Word 和出处分析 Markdown，并附跨卷引用排名
- **重点标记清单**：支持自定义标记类型与备注，绑定原文片段和来源，且**不修改原始资料**
- **文档与分类管理**：支持新建分类、批量导入、标签、备注、移动、删除、排序与过滤
- **备份与恢复**：可导出包含原始文档、解析文本和标签清单的 ZIP，并从 ZIP 恢复
- **离线 OCR**：扫描型 PDF 自动调用本机离线 OCR，建立可搜索索引
- **便于二次开发**：项目源码结构清晰，方便阅读、修改和扩展
- **AI 功能可控**：AI 辅助分析默认关闭；未配置 AI 服务时不会伪造内容，只显示文档原文和相应提示

## 🚀 安装与运行

### 1. 克隆仓库

```bash
git clone https://github.com/<你的账号>/本地学习库.git
cd 本地学习库
```

### 2. 创建虚拟环境并安装依赖

在 PowerShell 中运行：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt
```

### 3. 从源码启动

```powershell
.\.venv\Scripts\python.exe main.py
```

### 4. 重新打包

```powershell
.\build.ps1
```

打包生成文件位于：

```text
dist\智能文档学习库3.6.4.exe
```

## 📦 直接使用（打包版）

1. 双击 `智能文档学习库.exe`
2. 在顶部工具栏选择“导入到分类”；如需新分类，点击“新建分类”
3. 点击“添加文件”选择一个或多个资料，或点击“批量添加文件夹”
4. 等待程序完成文件复制、内容解析和索引建立
5. 在顶部输入 1–25 字关键词，按回车或点击“搜索原文”
6. 左侧以自动换行卡片展示原文片段；点选结果后，右侧显示完整原文并标黄关键词

## 📂 项目结构

```text
本地学习库/
├── assets/                  # 图标等资源文件
├── build.ps1                # Windows 打包脚本
├── document_converter.py    # Word、Markdown 转可搜索 PDF 等转换逻辑
├── exam_modules.py          # 试卷答案查找与导出相关模块
├── library_core.py          # 导入、索引、检索、分类与数据库操作
├── main.py                  # 程序入口与主界面
├── pdf_reader.py            # PDF 解析、文字提取与批注处理
├── pdf_viewer.py            # 内置 PDF 阅读器界面
├── question_research.py     # 文档问题检索整理与出处分析
├── requirements.txt         # Python 依赖清单
├── test_core.py             # 核心功能测试
├── test_exam_modules.py     # 试卷模块测试
├── test_exam_workflow.py    # 试卷流程测试
├── test_new_features.py     # 新增功能测试
└── 使用说明.md              # 详细使用说明与版本更新日志
```

## 🔑 关键文件

- `main.py`：程序启动入口
- `requirements.txt`：Python 依赖清单
- `build.ps1`：打包入口，运行后生成 Windows 可执行文件
- `使用说明.md`：详细使用方法与版本更新记录

## 💾 本地数据位置

默认保存在：

```text
C:\Users\你的用户名\AppData\Local\智能文档学习库\
```

其中：

- `资料文件`：保存导入的原始文件副本
- `学习库.db`：保存索引、完整解析文本、标签和元数据

> 所有数据仅在本机处理，不上传服务器。
